## What it does

`main.py` writes a single-line joke — at most 200 characters — giving
an excuse for a missed deadline, to `/output/entry.txt`.

> I missed the deadline because I estimated the job in developer days, and developer days are measured in dog years.

One sentence, first person, the punch at the end: the estimate was
measured in developer days, and developer days run on dog years. No
plain apology, no stock dog-ate-it retread — an optimistic estimate
that quietly turned into a unit conversion problem.

## Run

```sh
python3 main.py
# writes /output/entry.txt (or $ENTRY_OUT/entry.txt when ENTRY_OUT is set)
```
